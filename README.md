# 🗂 미션 - 로또 기능 목록

## 📚 기능 목록

### 입출력 요구 사항

- [ ] 로또 구입 금액을 1000원 단위로 입력 받는다.
    - [ ] ⚠️ 숫자를 입력하지 않으면 에러가 발생한다.
- [ ] 구입된 로또들의 목록을 오름차순으로 출력한다.
- [ ] 쉼표로 구분된 당첨 번호를 입력받는다.
    - [ ] ⚠️ 쉼표로 구분되지 않으면 에러가 발생한다.
    - [ ] ⚠️ 숫자를 입력하지 않으면 에러가 발생한다.
- [ ] 보너스 번호를 입력받는다.
    - [ ] ⚠️ 숫자를 입력하지 않으면 에러가 발생한다.
- [ ] 일치된 등수만큼의 당첨통계를 출력한다.
- [ ] 수익률을 둘째 자리에서 반올림하여 보여준다.

### 기능 요구 사항

- [ ] 구입금액을 1000으로 나누어 구매 횟수를 구한다.
    - [ ] ⚠️ 1000원 단위로 나누어 떨어지지 않을 경우 에러가 발생한다.
- [ ] 구매 횟수만큼 로또를 발행하고 오름차순으로 정렬한다.
- [x] 입력받은 당첨 번호를 검증한다.
    - [x] ⚠️ 중복된 번호가 있을경우 에러가 발생한다.
    - [x] ⚠️ 6개가 안될경우 에러가 발생한다.
    - [x] ⚠️ 1 ~ 45의 범위를 넘어갈경우 에러가 발생한다.
- [ ] 입력받은 보너스 번호를 검증한다.
    - [ ] ⚠️ 입력받은 당첨번호와 중복될경우 에러가 발생한다.
    - [ ] ⚠️ 1 ~ 45의 범위를 넘어갈경우 에러가 발생한다.
- [ ] 발행한 로또목록과 당첨번호,보너스 번호를 비교하여 일치한 로또를 센다
- [ ] 일치한 로또의 금액 합과 구매 금액으로 소수점 둘째자리에서 반올림해 수익률을 구한다.

### 프로그래밍 요구 사항

- [x] JDK 21 버전을 사용한다.
- [x] Application main() 에서 프로그래밍을 시작한다.
- [x] build.gradle을 변경하지 않는다.
- [x] System.exit()를 호출하지 않는다.
- [x] 사용자가 입력하는 값은 camp.nextstep.edu.missionutils.Console의 readLine()을 활용한다.
- [x] Random 값 추출은 camp.nextstep.edu.missionutils.Randoms의 pickUniqueNumbersInRange()를 활용한다.
- [x] Java Style Guide를 지키며 프로그래밍 한다.
- [x] 명시하지 않은 파일이나 패키지를 바꾸거나 이동하지 않는다.
- [x] indent(인덴트, 들여쓰기) depth를 3이 넘지 않도록 구현한다.
- [x] 3항 연산자를 쓰지 않는다.
- [x] 메소드가 한가지 일만 하게 만든다.
- [x] 테스트 코드를 작성한다.
